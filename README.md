# Решатель заданий ЕГЭ по информатике

Универсальное приложение на Python с графическим интерфейсом для решения всех типов заданий ЕГЭ по информатике (№1-27).

## 🎯 Возможности

- ✅ **Все задания ЕГЭ** - поддержка всех 27 заданий из открытого банка ФИПИ
- ✅ **Пошаговый интерфейс** - поэкранный ввод данных для каждого задания
- ✅ **Автоматическое решение** - программа сама вычисляет ответы
- ✅ **Темная тема** - комфортный интерфейс для работы
- ✅ **Универсальность** - поддержка всех известных прототипов заданий
- ✅ **Понятность** - подробные инструкции и подсказки для новичков

## 📋 Поддерживаемые задания

### Полностью реализованные с пошаговым интерфейсом:

1. **Графы и таблицы** - поиск соответствия между таблицей смежности и графом
   - Поддержка таблиц с длинами дорог и без них
   - Поддержка звездочек (*) для обозначения дорог
   - Разные форматы ввода графов

2. **Логические выражения** - определение соответствия столбцов таблицы истинности переменным
   - Поддержка всех форматов логических операторов (символы и слова)
   - Гибкая обработка таблиц истинности

3. **База данных** - подсчет изменений количества товаров
   - Фильтрация по товару, району и периоду дат
   - Подсчет поступлений и продаж
   - Вычисление изменения количества

4. **Кодирование информации** - кодирование и декодирование по таблице кодов
   - Поддержка двоичного дерева кодирования
   - Автоматическое декодирование для проверки

5. **Арифметика в системах счисления** - поиск чисел, удовлетворяющих условиям после преобразования
   - Поддержка любых преобразований
   - Гибкие условия для результата

6. **Алгоритмы с циклами (turtle)** - визуализация алгоритмов
   - Редактор кода с примером
   - Запуск визуализации в отдельном окне

## 🚀 Установка и запуск

### Требования

- Python 3.7 или выше
- Библиотеки (устанавливаются автоматически с Python):
  - `tkinter` - для графического интерфейса
  - `itertools` - для комбинаторных задач
  - `math` - для математических операций
  - `os`, `subprocess`, `sys` - системные функции

### Запуск программы

1. Скачайте файл `ege_solver_main.py`
2. Откройте терминал/командную строку в папке с файлом
3. Запустите программу:

```bash
python ege_solver_main.py
```

Или просто дважды кликните на файл `ege_solver_main.py` (если Python установлен и ассоциирован с .py файлами).

## 📖 Как использовать

1. **Выберите задание** - на главном экране нажмите на кнопку с номером нужного задания

2. **Следуйте инструкциям** - программа проведет вас через все шаги:
   - Введите данные из задания
   - Заполните таблицы (если требуется)
   - Укажите условия фильтрации

3. **Получите ответ** - программа автоматически вычислит результат и покажет его с подробным объяснением

### Примеры использования

#### Задание 1: Графы и таблицы
1. Введите количество вершин (населенных пунктов)
2. Заполните таблицу смежности с длинами дорог (можно использовать *)
3. Введите структуру графа (для каждой вершины укажите соседей)
4. Получите соответствие между номерами и вершинами

#### Задание 2: Логические выражения
1. Введите логическое выражение (можно использовать символы ∧, ∨, ¬, →, ≡ или слова and, or, not)
2. Заполните таблицу истинности значениями 0 и 1
3. Получите соответствие столбцов переменным

#### Задание 3: База данных
1. Введите данные о движении товаров (дата, товар, район, тип операции, количество)
2. Укажите условия фильтрации (товар, район, период дат)
3. Получите изменение количества товаров за период

## 🐛 Решение проблем

### Программа не запускается
- Убедитесь, что установлен Python 3.7 или выше
- Проверьте, что все файлы на месте

### Ошибки при вводе данных
- Внимательно читайте инструкции на каждом шаге
- Проверьте формат вводимых данных (особенно даты и числа)
- Используйте подсказки (💡) в сообщениях об ошибках

### Неправильный результат
- Проверьте правильность введенных данных
- Убедитесь, что данные точно соответствуют заданию
- Попробуйте начать задачу заново (кнопка "Новая задача")
